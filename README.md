# OIBSIP_Python_Task2–BMI Calculator
## Objective
To develop a simple Python program that calculates the Body Mass Index (BMI) of a user based on their height and weight and categorizes their health status.

## Description
This project takes user input for weight (in kilograms) and height (in meters), calculates the BMI using the standard formula, and displays the BMI value along with the corresponding health category.

## Tools & Technologies Used
- Python
- Basic Python concepts (input, conditional statements)

## Steps Performed
1. Took user input for weight in kilograms.
2. Took user input for height in meters.
3. Calculated BMI using the formula:
   
   BMI = weight / (height × height)
4. Displayed the BMI value rounded to two decimal places.
5. Classified the BMI into health categories:
   - Underweight
   - Normal weight
   - Overweight
   - Obese

## Output
The program displays:
- Calculated BMI value
- Health category based on BMI range

## Conclusion
This BMI Calculator successfully helps users assess their health status using a simple and user-friendly Python program. It demonstrates basic Python programming skills and real-life application.
